# LAB-8 기대 결과

| 단계 | 기대 결과 |
| --- | --- |
| 임시 채팅 켜기 | 화면에 임시 채팅 표시가 보인다. 저장하지 않으면 이 대화는 대화 기록에 남지 않는다. 개인화 선택지가 나오면 「Unpersonalized」 쪽을 골랐다 |
| 요청 1 | 질문 하나만 나온다(예: 「AI 에이전트에게 맡기고 싶은 업무는 무엇이고, 최종 결과물은 어떤 형태인가요?」) |
| 답하기 | 답할 때마다 다음 질문 하나가 나온다. 모두 7개 이내 |
| 기관 이름이나 사람 이름을 적었을 때 | 「실습에서는 일반적인 말로 바꿔 적어 주세요」라는 안내가 나오고, 표에 옮기지 않는다 |
| 질문이 끝났을 때 | 세 항목과 승인 지점 표(단계, 에이전트에게 맡길 일, 사람이 하는 일, 승인 지점, 승인자, 판정 기준)가 나온다. 답하지 않은 칸은 「확인 필요」 |
| 옆 사람과 바꿔 읽기 | 빠진 승인 지점을 하나 적어 준다(예: 「외부 서비스에 자료를 넣기 전 확인」, 「규정이 바뀌면 다시 시험」) |

강사 사전 실행(codex)에서는 요청 1에 질문 하나만 나왔고, 기관 이름·사람 이름·건수를 넣은 답에 「실습에서는 일반적인 말로 바꿔 적어 주세요」 안내가 나왔으며, 요청 2로 끝낸 표에 그 이름과 건수가 들어가지 않았습니다. 임시 채팅 화면은 강사가 미리 확인합니다.

## 막혔을 때

| 증상 | 할 일 |
| --- | --- |
| 질문을 한꺼번에 여러 개 한다 | 「질문은 하나씩만 해 줘」를 보낸다 |
| 질문이 7개를 넘는다 | 「요청 2」를 보내 표를 만든다 |
| 임시 채팅 메뉴가 안 보인다 | 일반 대화로 하고, 표를 옮긴 뒤 대화를 지운다 |
| 메모장에 붙인 표의 칸이 어긋난다 | 칸의 글이 다 들어갔으면 그대로 둔다. 글이 빠졌으면 그 줄만 다시 복사한다 |
| 내 업무가 떠오르지 않는다 | 「회의록 초안 작성」, 「공공데이터로 월간 통계표 만들기」, 「입찰 공고문 필수 항목 점검」 가운데 하나로 한다 |
| 표가 나오기 전에 시간이 끝났다 | `완성본/새별_예.md`의 표 양식에 손으로 채운다 |
