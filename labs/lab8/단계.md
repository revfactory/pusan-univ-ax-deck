# LAB-8 내 업무의 승인 지점 표 만들기

> 실습 규칙: 기관 이름, 사람 이름, 내부 수치, 실제 문서 내용을 입력하지 않습니다. 업무는 일반적인 말로 적습니다(예: 「계약 서류의 필수 항목 누락 점검」).

## 파일 다루기

- 실습 묶음은 GitHub 저장소 `github.com/revfactory/pusan-univ-ax-deck`에서 초록색 「Code」 단추 → 「Download ZIP」으로 받습니다. 받은 압축 파일(.zip)을 풀어 내 컴퓨터(예: 바탕 화면)에 두면, 그 안의 `labs` 폴더가 실습 묶음입니다. 파일을 열고 저장하고 ChatGPT에 첨부할 때는 압축을 푼 폴더 안의 파일을 씁니다.
- `.md` 파일은 Windows에서는 메모장, macOS에서는 텍스트 편집기로 엽니다. 다른 프로그램이 열리면 Windows는 파일을 오른쪽 클릭하고 「연결 프로그램」에서, macOS는 파일을 Control-클릭하고 「다음으로 열기」에서 고릅니다. 파일이 열리지 않으면 손을 듭니다.
- 붙여 넣을 요청문은 `` ```text `` 줄과 `` ``` `` 줄 사이에 있습니다. 두 줄 사이의 글만 복사합니다. `` ```text `` 줄과 `` ``` `` 줄은 복사하지 않습니다.
- 고른 글은 복사하고(Windows는 Ctrl+C, macOS는 Command+C), ChatGPT 입력창에 붙여 넣습니다(Windows는 Ctrl+V, macOS는 Command+V).
- 채운 양식은 메모장이나 텍스트 편집기에서 같은 이름으로 저장합니다(Windows는 Ctrl+S, macOS는 Command+S).
- 이 실습에서 저장할 파일: `승인지점표_양식.md`(임시 채팅 창을 닫기 전에 옮깁니다. 맨 아래 칸은 옆 사람이 내 노트북에서 채웁니다)

## 실습 순서

오늘 새별시설공단 사례로 한 일(세 항목 요청문, 시험, 검토, 승인)을 내 업무 하나에 옮겨 봅니다.

1. ChatGPT에서 새 대화를 열고 임시 채팅을 켭니다. 켜는 곳은 강사가 먼저 보여 줍니다.
   - 첫 메시지를 보내기 전에 개인화 여부를 고르는 선택지가 나오면 메모리와 맞춤 지침을 쓰지 않는 쪽(영어 화면 「Unpersonalized」)을 고릅니다. 대화를 시작한 뒤에는 바꿀 수 없습니다.
   - 임시 채팅은 저장하지 않으면 대화 기록에 남지 않고, 임시 상태인 동안 모델 개선에 쓰이지 않습니다. 다만 OpenAI가 안전 목적으로 사본을 최대 30일 보관할 수 있으므로, 임시 채팅에서도 실습 규칙(맨 위)을 지킵니다.
   - 임시 채팅을 저장하지 않습니다. 저장하면 대화 기록에 남는 일반 대화가 됩니다.
2. 「요청 1」을 보냅니다. 질문이 하나씩 나옵니다.
3. 질문마다 짧게 답합니다. 업무는 일반적인 말로 적습니다. 질문이 끝나면 세 항목과 승인 지점 표가 나옵니다.
4. 저장하지 않은 임시 채팅은 창을 닫으면 다시 열 수 없습니다. 표가 나오면 다른 일보다 먼저 `승인지점표_양식.md`에 옮깁니다.
   - `승인지점표_양식.md`를 메모장(macOS는 텍스트 편집기)으로 엽니다.
   - 답변의 세 항목을 마우스로 끌어 선택하고 Ctrl+C(macOS는 Command+C)로 복사해 「## 세 항목」 줄 아래에 붙입니다. 승인 지점 표도 같은 방법으로 「## 승인 지점 표」 줄 아래에 붙입니다. 양식에 원래 있던 빈 칸 줄은 지우지 않아도 됩니다.
   - 표 모양이 화면과 달라도 칸의 글이 다 들어가면 됩니다. 같은 이름으로 저장합니다.
   - 「## 시험해 볼 것」 칸은 오늘 비워 두어도 됩니다. 파트 3 9장에서 내일 할 일로 다시 봅니다.
5. 옆 사람과 표를 바꿔 읽습니다.
   - 옆 사람과 노트북을 바꿉니다. 파일은 주고받지 않습니다.
   - 옆 사람 노트북에 열린 `승인지점표_양식.md`를 읽고, 빠진 승인 지점을 하나 찾아 맨 아래 「## 옆 사람이 찾은 빠진 승인 지점」 칸에 적습니다.
   - 적은 사람이 저장(Ctrl+S, macOS는 Command+S)하고 노트북을 돌려줍니다.

막히면 `완성본/새별_예.md`를 봅니다. 오늘 실습의 민원 답변 업무를 같은 표로 정리한 예입니다.

## 요청 1

```text
나는 공공기관 직원이다. 내 업무 하나를 AI 에이전트에게 맡길 수 있는지 정리하려고 한다. 너는 질문을 한 번에 하나씩 하는 인터뷰 진행자다.

규칙
- 질문은 한 번에 하나만 한다. 내가 답하면 다음 질문을 한다. 질문은 모두 7개 이내로 한다.
- 기관 이름, 사람 이름, 내부 수치, 실제 문서 내용은 묻지 않는다. 내가 그런 것을 적으면 「실습에서는 일반적인 말로 바꿔 적어 주세요」라고 알려 주고, 표에는 옮기지 않는다.
- 물어볼 것: 업무 이름과 결과물, 업무에 쓰는 자료와 그 자료를 외부 서비스에 넣어도 되는지, 결과가 맞는지 판단하는 기준, 결과에 책임지는 사람의 직위나 역할, 틀렸을 때 생기는 일.

질문이 끝나면 아래 두 가지를 만든다.
1. 세 항목: [목적과 결과물] [참고 자료와 제외 범위] [완료 기준과 승인 조건]
2. 승인 지점 표: | 단계 | 에이전트에게 맡길 일 | 사람이 하는 일 | 승인 지점(여기서 멈춘다) | 승인자(직위나 역할) | 판정 기준 |

첫 질문부터 시작해.
```

## 요청 2(질문이 너무 많을 때)

```text
질문은 여기까지 하고, 지금까지 답한 내용으로 세 항목과 승인 지점 표를 만들어 줘. 모르는 칸은 「확인 필요」로 적어.
```
