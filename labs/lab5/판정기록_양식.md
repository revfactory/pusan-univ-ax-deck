## 다시 쓰기

| 초안 | 다시 쓰기 횟수 | 다시 쓴 초안의 금액 | 다시 검토 판정 |
| --- | --- | --- | --- |
| B | 1 | | |
| C(선택) | 1 | | |

한 초안을 두 번째로 다시 쓰면 그 초안 줄을 하나 더 만들고 횟수 칸에 2를 적습니다. 두 번째 다시 검토 요청의 맨 윗줄도 「[다시 쓰기 횟수] 2회」로 고쳐 보냅니다.

## 복사해 옮긴 횟수

프로젝트에 보낸 요청 하나를 1회로 셉니다. 요청 하나를 채우려고 여러 번 복사했어도 1회입니다.

| 옮긴 것 | 어디서 어디로 | 횟수 |
| --- | --- | --- |
| 초안 | `검토할_초안.md`(민원 상담 프로젝트가 쓴 것으로 가정) → 검토 프로젝트 | |
| 검토 의견 | 검토 프로젝트 → 민원 상담 프로젝트 | |
| 다시 쓴 초안 | 민원 상담 프로젝트 → 검토 프로젝트 | |
| 합계 | | |

초안 3건이면 최소 5회(초안 B만 다시 쓴 경우), 초안 C까지 다시 쓰면 7회입니다. 민원이 하루 30건이고 그 가운데 3분의 1이 다시 쓰기를 한 번 받는다고 가정하면 하루 몇 회가 될지 한 줄로 적습니다(가정은 실습 묶음이 정한 것입니다): ____
