# LAB-5 「새별 답변 검토」 프로젝트로 초안 판정하기

> 가상 사례 실습입니다. 이 묶음의 가상 자료만 입력합니다.

## 파일 다루기

- 실습 묶음은 GitHub 저장소 `github.com/revfactory/pusan-univ-ax-deck`에서 초록색 「Code」 단추 → 「Download ZIP」으로 받습니다. 받은 압축 파일(.zip)을 풀어 내 컴퓨터(예: 바탕 화면)에 두면, 그 안의 `labs` 폴더가 실습 묶음입니다. 파일을 열고 저장하고 ChatGPT에 첨부할 때는 압축을 푼 폴더 안의 파일을 씁니다.
- `.md` 파일은 Windows에서는 메모장, macOS에서는 텍스트 편집기로 엽니다. 다른 프로그램이 열리면 Windows는 파일을 오른쪽 클릭하고 「연결 프로그램」에서, macOS는 파일을 Control-클릭하고 「다음으로 열기」에서 고릅니다. 파일이 열리지 않으면 손을 듭니다.
- 붙여 넣을 요청문은 `` ```text `` 줄과 `` ``` `` 줄 사이에 있습니다. 두 줄 사이의 글만 복사합니다. `` ```text `` 줄과 `` ``` `` 줄은 복사하지 않습니다.
- 고른 글은 복사하고(Windows는 Ctrl+C, macOS는 Command+C), ChatGPT 입력창에 붙여 넣습니다(Windows는 Ctrl+V, macOS는 Command+V).
- 채운 양식은 메모장이나 텍스트 편집기에서 같은 이름으로 저장합니다(Windows는 Ctrl+S, macOS는 Command+S).
- 이 실습에서 저장할 파일: `판정기록_양식.md`

## 실습 순서

민원 상담 프로젝트가 쓴 답변을 같은 프로젝트에게 다시 확인시키면 자기 답을 그대로 맞다고 하기 쉽습니다. 이 실습에서는 검토만 하는 프로젝트를 따로 만들어 초안을 판정합니다.

1. 사이드바에서 새 프로젝트를 만들고 이름을 「새별 답변 검토」로 합니다.
2. 프로젝트 설정의 지침 칸에 `검토_지침.md`의 상자 안 글을 붙여 넣고 저장합니다.
3. 프로젝트 파일에 아래 2개를 올립니다.
   - `자료/새별_체육시설_이용규정.md`
   - `자료/새별_공영주차장_운영지침.md`
4. 검토 프로젝트 안에서 새 대화를 열고 `검토할_초안.md`의 「초안 A」 상자를 통째로 붙여 넣습니다. 초안 B, 초안 C도 각각 새 대화에서 같은 방법으로 보냅니다.
5. 판정과 이유를 `판정기록_양식.md`에 적습니다.
6. 「다시 쓰기」를 받은 초안 B를 「새별 민원 상담」 프로젝트에서 다시 쓰게 합니다.
   - 먼저 새 메모장 창(macOS는 텍스트 편집기의 새 문서)을 열고 `검토할_초안.md`의 「다시 쓰기 요청」 상자 안 글을 붙여 넣습니다.
   - 괄호 줄을 메모장에서 채웁니다. [원 민원]과 [초안]은 `검토할_초안.md`의 「초안 B」 상자에서, [검토 의견]은 검토 프로젝트 답의 [고칠 내용]에서 복사해 옵니다. 괄호 줄 「(… 붙여 넣는다)」는 지웁니다.
   - 다 채운 글을 통째로 복사해 「새별 민원 상담」 프로젝트 안의 새 대화에 붙여 넣고 보냅니다.
   - 채우는 동안 여러 대화를 오가며 복사해 와야 하므로, 입력창이 아니라 메모장에서 채웁니다.
7. 다시 쓴 초안을 검토 프로젝트에서 다시 검토하게 합니다.
   - 6번처럼 새 메모장 창에 「다시 검토 요청」 상자 안 글을 붙여 넣고 채웁니다. [원 민원]은 「초안 B」 상자에서, [초안]은 6번에서 받은 다시 쓴 답 전체에서 복사해 옵니다.
   - 다 채운 글을 통째로 복사해 검토 프로젝트 안의 새 대화에 붙여 넣고 보냅니다.
   - 다시 검토에서 또 「다시 쓰기」가 나오면 새 [고칠 내용]으로 6번을 한 번 더 하고, 두 번째로 다시 검토할 때 「다시 검토 요청」 상자 맨 윗줄을 「[다시 쓰기 횟수] 2회」로 고칩니다. 2회에도 「다시 쓰기」가 나오면 검토 프로젝트가 「사람에게 넘김」으로 판정합니다(아래 규칙).
   - 시간이 남으면 초안 C도 6\~7을 합니다. 초안 C를 두 번째로 다시 검토할 때도 [다시 쓰기 횟수]를 2회로 고칩니다.
8. 두 프로젝트 사이에 글을 복사해 옮긴 횟수를 세어 판정 기록 아래 칸에 적습니다. 파트 2 9장의 시연(DEMO-2)에서 이 횟수와 비교합니다.

## 규칙

- 다시 쓰기는 한 초안에 2회까지입니다. 2회 다시 써도 「다시 쓰기」가 나오면 검토 프로젝트가 「사람에게 넘김」으로 판정합니다. 그 초안은 담당자가 직접 씁니다.
- 「통과」는 발송 승인이 아닙니다. 발송은 고객지원팀장이 정합니다(`자료/새별_담당부서_안내.md`의 민원 답변 발송 절차).
- 검토 프로젝트도 틀릴 수 있습니다. 금액은 `lab4/시험표.md`나 규정 원문으로 내가 다시 확인합니다.
