# LAB-2 민원 데이터로 시범 범위 정하기

> 가상 사례 실습입니다. `민원접수목록_2026_3분기.csv`는 가상 자료이고 개인정보 칸이 없습니다.

## 파일 다루기

- 실습 묶음은 GitHub 저장소 `github.com/revfactory/pusan-univ-ax-deck`에서 초록색 「Code」 단추 → 「Download ZIP」으로 받습니다. 받은 압축 파일(.zip)을 풀어 내 컴퓨터(예: 바탕 화면)에 두면, 그 안의 `labs` 폴더가 실습 묶음입니다. 파일을 열고 저장하고 ChatGPT에 첨부할 때는 압축을 푼 폴더 안의 파일을 씁니다.
- `.md` 파일은 Windows에서는 메모장, macOS에서는 텍스트 편집기로 엽니다. 다른 프로그램이 열리면 Windows는 파일을 오른쪽 클릭하고 「연결 프로그램」에서, macOS는 파일을 Control-클릭하고 「다음으로 열기」에서 고릅니다. 파일이 열리지 않으면 손을 듭니다.
- 붙여 넣을 요청문은 `` ```text `` 줄과 `` ``` `` 줄 사이에 있습니다. 두 줄 사이의 글만 복사합니다. `` ```text `` 줄과 `` ``` `` 줄은 복사하지 않습니다.
- 고른 글은 복사하고(Windows는 Ctrl+C, macOS는 Command+C), ChatGPT 입력창에 붙여 넣습니다(Windows는 Ctrl+V, macOS는 Command+V).
- 채운 양식은 메모장이나 텍스트 편집기에서 같은 이름으로 저장합니다(Windows는 Ctrl+S, macOS는 Command+S).
- 이 실습에서 저장할 파일: `범위_판단표.md`

## 실습 순서

1. 새 대화를 열고 `자료/민원접수목록_2026_3분기.csv`를 첨부합니다.
2. 「요청 1」을 보냅니다. 유형별 표를 받습니다.
3. 「요청 2」를 보냅니다. 막대 차트를 받습니다.
4. 「요청 3」을 보내 건수를 센 코드를 받습니다. 코드에 CSV 파일(`민원접수목록_2026_3분기.csv`)을 여는 줄과 「민원유형」별로 묶어 세는 줄이 있으면 코드로 센 숫자입니다. 묶어 세는 줄에는 보통 `groupby`, `value_counts`, `Counter` 같은 말이 들어갑니다.
5. 「요청 4」를 보내 답변근거 칸이 비어 있는 비율을 봅니다. 답변근거가 채워진 유형이 규정으로 답이 정해지는 유형입니다. `범위_판단표.md`를 채우고 시범 범위 두 유형을 고릅니다. 이 판단은 사람이 합니다.

## 요청 1

```text
첨부한 CSV는 새별시설공단의 2026년 3분기 민원 접수 목록(가상 자료)이다.
파이썬 코드를 실행해서 민원유형별 건수, 전체 대비 비율(%), 평균 처리일수(소수 둘째 자리)를 표로 보여 줘.
건수가 많은 순서로 정렬하고, 마지막 줄에 합계를 넣어 줘.
```

## 요청 2

```text
민원유형별 건수를 막대 차트로 그려 줘. 막대 위에 건수를 적어 줘.
```

## 요청 3

```text
건수와 평균 처리일수를 계산한 코드를 보여 줘.
```

## 요청 4

```text
민원유형마다 「답변근거」 칸이 비어 있는 비율을 표로 보여 줘.
```
