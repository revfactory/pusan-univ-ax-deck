# LAB-4 시험하고 지침 고치기

> 가상 사례 실습입니다.

## 파일 다루기

- 실습 묶음은 GitHub 저장소 `github.com/revfactory/pusan-univ-ax-deck`에서 초록색 「Code」 단추 → 「Download ZIP」으로 받습니다. 받은 압축 파일(.zip)을 풀어 내 컴퓨터(예: 바탕 화면)에 두면, 그 안의 `labs` 폴더가 실습 묶음입니다. 파일을 열고 저장하고 ChatGPT에 첨부할 때는 압축을 푼 폴더 안의 파일을 씁니다.
- `.md` 파일은 Windows에서는 메모장, macOS에서는 텍스트 편집기로 엽니다. 다른 프로그램이 열리면 Windows는 파일을 오른쪽 클릭하고 「연결 프로그램」에서, macOS는 파일을 Control-클릭하고 「다음으로 열기」에서 고릅니다. 파일이 열리지 않으면 손을 듭니다.
- 붙여 넣을 요청문은 `` ```text `` 줄과 `` ``` `` 줄 사이에 있습니다. 두 줄 사이의 글만 복사합니다. `` ```text `` 줄과 `` ``` `` 줄은 복사하지 않습니다.
- 고른 글은 복사하고(Windows는 Ctrl+C, macOS는 Command+C), ChatGPT 입력창에 붙여 넣습니다(Windows는 Ctrl+V, macOS는 Command+V).
- 채운 양식은 메모장이나 텍스트 편집기에서 같은 이름으로 저장합니다(Windows는 Ctrl+S, macOS는 Command+S).
- 이 실습에서 저장할 파일: `시험기록_양식.md`. 고친 지침은 프로젝트 설정에 저장합니다. 질문은 `시험질문.md`에서 복사합니다(`시험표.md`는 표라서 질문만 고르기 어렵습니다)

## 실습 순서

1. 「새별 민원 상담」 프로젝트 안에서 새 대화를 엽니다.
2. `시험질문.md`의 T01\~T12 질문을 하나씩 보냅니다. 질문마다 `` ```text `` 줄과 `` ``` `` 줄 사이의 한 줄만 복사해 붙여 넣습니다. 답이 다 나오면 다음 질문을 보냅니다.
   - 시간이 모자라면 옆 사람과 나눕니다. 옆 사람의 프로젝트도 지침 1판과 규정 파일 3개가 들어 있어 내 프로젝트와 같을 때만 나눕니다. 홀수 번호(T01, T03 …)는 내가, 짝수 번호(T02, T04 …)는 옆 사람이 보내고, 결과를 서로 알려 주어 각자 시험 기록에 12개를 모두 적습니다.
3. 답을 `시험표.md`의 기대 답·기대 근거와 대조해 `시험기록_양식.md`의 1회차 표를 채웁니다.
4. 실패한 시험마다 원인을 고릅니다. 실패가 없으면 4\~6번을 건너뛰고 7번으로 갑니다.
   - 지침: 지침에 규칙이 없거나 모호하다.
   - 파일: 규정 파일에 내용이 없거나 찾기 어렵다.
   - 시험표: 기대 답이 틀렸거나 질문이 모호하다.
5. 실패한 시험마다 지침을 한 곳씩 고쳐 프로젝트 설정에 저장합니다. 한 번에 한 곳을 고치고, 그 수정과 관련된 시험을 6번에서 다시 보냅니다. 무엇을 고칠지 모르겠으면 「요청 1」을 씁니다. 그래도 막히면 `완성본/지침_2판.md`를 붙여 넣습니다.
6. 지침을 저장한 뒤 프로젝트 안에서 새 대화를 열고, 실패한 시험만 다시 보냅니다. 같은 시험을 두 번 보내 두 번 다 같은 판정인지 봅니다(답은 보낼 때마다 다를 수 있습니다).
   - LAB-3에서 옮겨 온 Q3 때문에 지침의 역할 문장을 고쳤으면 `lab3/확인질문.md`의 Q3도 같은 방법으로 다시 보내고, 2회차 표에 「Q3」으로 적습니다.
   - (선택) 시간이 남으면 T10도 한 번 더 보내 봅니다. 강사 사전 실행에서는 지침을 고친 중간안이 1판에서 통과하던 T10을 깨뜨렸습니다.
7. 2회차 결과와 남는 위험을 적습니다. 모두 통과했으면 추가 시험 T13·T14(`시험질문.md` 맨 아래)를 보내 봅니다.

