## 요청 1(기본 경로: Work에서 Sites로)

ChatGPT 웹에서 「Work」를 고르고, 파일 4개를 첨부한 뒤 보냅니다.

```text
@Sites 첨부한 파일 4개로 「새별시설공단 민원 안내」 website를 만들어 줘. 새별시설공단은 실습용 가상 기관이다.
만들기 전에 계획을 먼저 보여 주고 내 승인을 받은 뒤 시작해.

[항목 1. 목적과 결과물]
- 읽는 사람: 새별체육센터 강습 수강생과 공영주차장 이용자. 휴대폰으로도 본다.
- 목적: 민원인이 환불 금액과 주차 요금을 스스로 계산해 보고, 근거 조문과 담당 부서를 한 화면에서 본다.
- 화면 구성(한 페이지, 위에서 아래로):
  1. 수강료 환불 계산: 강습 종류(수영 초급, 수영 중급, 요가, 아쿠아로빅, 헬스 자유이용), 낸 수강료(강습을 고르면 규정의 금액이 기본값으로 들어가고 고칠 수 있다), 진행된 강습 횟수, 「강습 시작일 전날까지 신청」 선택, 「질병·부상 의사 진단서 또는 공단 사정」 선택. 헬스 자유이용을 고르면 횟수 대신 이용 시작일과 환불 신청일을 받는다.
  2. 주차 요금 계산: 주차장(새별역, 새별체육센터, 새별문화센터), 주차 시간(시간, 분), 감면 대상(여러 개 고를 수 있다), 「시설 이용 확인을 받았다」 선택(체육센터·문화센터 주차장만).
  3. 계산 결과마다 금액, 계산식, 근거 조문(규정 이름과 제○조 제○항 제○호)을 함께 보여 준다.
  4. 자주 묻는 질문 검색: 자주묻는질문.md의 15개 항목에서 찾는다. 결과가 없으면 담당 부서 표를 보여 준다.
  5. 담당 부서 안내 표.
  6. 상담 창: 정해 둔 예시 질문 3개에 정해 둔 답만 보여 준다. 화면에 「시범 화면: 정해 둔 답만 보여 줍니다」라고 적는다.
- 맨 아래에 「가상 기관 실습 화면입니다. 계산 결과는 안내용이며 최종 금액은 담당자가 확인합니다.」를 적는다.

[항목 2. 참고 자료와 제외 범위]
- 계산 규칙은 첨부한 규정 파일만 따른다. 감면이 두 가지 이상이면 가장 높은 하나만 적용하고, 10원 미만은 버린다.
- 대관, 시설 고장, 사고·분쟁, 과태료는 계산하지 않고 담당 부서를 안내한다.
- 이름, 전화번호, 주민등록번호를 입력받는 칸을 만들지 않는다. 입력한 값을 저장하거나 밖으로 보내지 않는다.

[항목 3. 완료 기준과 승인 조건]
- 완료 전에 아래 값이 나오는지 직접 확인하고, 확인한 결과를 표로 보여 줘.
  - 요가(40,000원, 8회) 2회 진행 → 26,000원, 체육시설 이용 규정 제7조 제1항 제2호
  - 아쿠아로빅(50,000원, 8회) 3회 진행, 의사 진단서 있음 → 31,250원
  - 수영 초급(60,000원, 12회) 6회 진행 → 환불 없음, 제7조 제1항 제3호
  - 경차, 새별역 공영주차장 2시간 40분 → 2,450원
  - 장애인 표지 차량 + 전기차, 1시간 5분 → 440원
  - 검색어 「대관」 → 문화센터 운영팀(내선 2301)
- 게시(공개)는 내가 정한다. 공개 범위를 바꾸거나 게시하기 전에 나에게 묻는다.
```

## 요청 2(값이 틀렸을 때)

미리보기나 내려받은 파일에서 확인한 값이 기대 값과 다를 때 보냅니다. 빈칸을 채웁니다.

```text
화면에서 확인한 값이 규정과 다르다. 아래 경우를 고쳐 줘. 고친 뒤 같은 값을 다시 계산해 표로 보여 줘.
- 입력: ____
- 화면에 나온 값: ____
- 기대 값과 근거: ____
다른 계산 결과는 바꾸지 마.
```

## 요청 3(수정 한 번)

```text
두 가지를 고쳐 줘.
```
