# LAB-7 민원 안내 화면 만들기(Work·Sites)

> 가상 사례 실습입니다. 첨부하는 파일 4개는 모두 가상 자료입니다.

## 파일 다루기

- 실습 묶음은 GitHub 저장소 `github.com/revfactory/pusan-univ-ax-deck`에서 초록색 「Code」 단추 → 「Download ZIP」으로 받습니다. 받은 압축 파일(.zip)을 풀어 내 컴퓨터(예: 바탕 화면)에 두면, 그 안의 `labs` 폴더가 실습 묶음입니다. 파일을 열고 저장하고 ChatGPT에 첨부할 때는 압축을 푼 폴더 안의 파일을 씁니다.
- `.md` 파일은 Windows에서는 메모장, macOS에서는 텍스트 편집기로 엽니다. 다른 프로그램이 열리면 Windows는 파일을 오른쪽 클릭하고 「연결 프로그램」에서, macOS는 파일을 Control-클릭하고 「다음으로 열기」에서 고릅니다. 파일이 열리지 않으면 손을 듭니다.
- 붙여 넣을 요청문은 `` ```text `` 줄과 `` ``` `` 줄 사이에 있습니다. 두 줄 사이의 글만 복사합니다. `` ```text `` 줄과 `` ``` `` 줄은 복사하지 않습니다.
- 고른 글은 복사하고(Windows는 Ctrl+C, macOS는 Command+C), ChatGPT 입력창에 붙여 넣습니다(Windows는 Ctrl+V, macOS는 Command+V).
- 채운 양식은 메모장이나 텍스트 편집기에서 같은 이름으로 저장합니다(Windows는 Ctrl+S, macOS는 Command+S).
- 이 실습에서 저장할 파일: `목과_실제_구분표.md`. 대체 경로로 하면 `index.html`(내려받은 파일이나 메모장·텍스트 편집기로 저장한 파일)도 저장합니다

## 만드는 것

수강료 환불과 주차 요금을 계산하고 근거 조문을 보여 주는 「새별시설공단 민원 안내」 화면을 만듭니다. 기본 경로는 ChatGPT Work에서 Sites로 만들어 미리보기로 여는 것이고, Work나 Sites를 쓸 수 없으면 대체 경로로 HTML 파일을 받아 브라우저로 엽니다. 결과는 같은 화면입니다.

## 시작 전에

- Work와 Sites 만들기는 Codex와 같은 사용량을 씁니다. 한도를 다 쓰면 크레딧 구매 화면이 나올 수 있습니다. 그 화면이 나오면 사지 않고 대체 경로로 갑니다.
- 설정 → 데이터 관리의 「모델 개선을 위한 데이터 학습 허용」이 켜져 있으면 Sites를 만들거나 고친 대화가 학습에 쓰일 수 있습니다. 실습 전에 확인합니다.
- 새 사이트는 비공개로 시작합니다. 6단계에서 공개 범위를 정하기만 하고, 다른 사람을 넣거나 게시하지 않습니다. 참가자끼리 서로의 사이트 링크를 열어 보지 않습니다.

## 기본 경로: Work에서 Sites로

1. ChatGPT 웹에서 「Work」를 고르고 새 대화를 엽니다. 파일 4개(`화면_요청문.md` 맨 위 목록)를 첨부합니다. Work가 보이지 않으면 대체 경로로 갑니다.
2. `화면_요청문.md`의 「요청 1」을 붙여 넣고 보냅니다. 계획이 먼저 나오면 화면 구성 6개와 완료 기준이 계획에 들어 있는지 읽고 승인합니다. 빠진 것이 있으면 승인하지 않고 「○○가 계획에 없다. 넣어서 다시 보여 줘」를 보냅니다.
   - 승인 단추가 보이지 않으면 같은 대화에 「계획을 승인한다. 이 계획대로 만들어 줘」를 보냅니다. 그래도 만들기가 시작되지 않으면 강사에게 알리고 대체 경로로 갑니다.
3. 미리보기가 열리면 확인 세 가지를 직접 입력해 봅니다.
   - 요가, 수강료 40,000원, 진행 2회 → 26,000원, 체육시설 이용 규정 제7조 제1항 제2호(시험표 T01)
   - 경차, 새별역 공영주차장, 2시간 40분 → 2,450원(시험표 T06)
   - 자주 묻는 질문에서 「대관」 검색 → 문화센터 운영팀(내선 2301)
   틀린 값이 있으면 「요청 2」의 빈칸을 채워 보냅니다.
4. `목과_실제_구분표.md`를 채웁니다. 실제로 계산하는 부분과 정해 둔 답만 보여 주는 부분(목)을 나눕니다.
5. 「요청 3」으로 한 번 고칩니다. 바뀐 미리보기에서 3단계의 첫 번째 값을 다시 확인합니다.
6. 공유 화면을 열어 공개 범위의 선택지를 봅니다(선택지는 계정마다 다를 수 있습니다). 이 화면을 시범 운영에 쓴다면 어느 범위로 열지 정하고 이유를 `목과_실제_구분표.md` 아래 칸에 적습니다. 사람을 넣거나 게시하지 않고 공유 화면을 닫습니다.
7. 사이트는 비공개 그대로 둡니다. 필요 없으면 지웁니다.

먼저 끝났으면 「요청 4」로 헬스 자유이용 환불과 시설 이용 확인 주차 요금을 확인합니다.

## 대체 경로: Chat에서 HTML 파일로

1. Chat에서 새 대화를 열고 같은 파일 4개를 첨부합니다.
2. `화면_요청문.md`의 「요청 1-파일」을 붙여 넣고 보냅니다.
3. 답변 끝의 내려받기 링크로 `index.html`을 받습니다. ChatGPT가 만든 파일의 링크는 빨리 만료되므로 답이 나오면 바로 받습니다. 받은 파일을 더블클릭하거나 브라우저 창으로 끌어 놓아 엽니다.
   - 내려받기 링크가 없으면 「index.html의 전체 코드를 코드 상자 하나로 보여 줘」를 보냅니다. 코드 상자의 복사 단추를 누르고, 메모장(Windows)이나 텍스트 편집기(macOS, 「일반 텍스트」로 바꾼 뒤)에 붙여 넣어 `index.html`로 저장합니다.
4. 기본 경로의 3\~5단계를 같은 방법으로 합니다. 고친 파일은 다시 내려받습니다.
5. 파일이 열리지 않거나 값이 계속 틀리면 `완성본/index.html`을 엽니다.

이 경로는 링크로 공유하지 않습니다. 동료에게 보여 줄 때는 파일을 직접 건넵니다.

## 선택 확장(API 키가 지급된 경우에만)

상담 창을 정해 둔 답 대신 실제 AI 답변으로 바꿀 수 있습니다. 사이트 설정의 비밀 값(환경 변수)에 API 키를 직접 넣고, 「API 키는 서버 쪽에서만 쓰고 화면 코드에 넣지 마」라고 요청합니다. 키를 대화창에 붙여 넣지 않습니다. API 사용 요금은 ChatGPT Plus와 별도로 청구됩니다.

- 도움말에 따르면 사이트 구성에 키를 새로 더하면 게시해야 적용됩니다. 게시하지 않은 미리보기에서 그 키가 쓰이는지는 문서에 없습니다.
- 이 실습은 선택 확장에서도 게시하지 않습니다. 미리보기에서 실제 답이 나오지 않으면 거기서 멈춥니다.
