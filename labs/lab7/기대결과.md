# LAB-7 기대 결과

## 기본 경로(Work → Sites)

| 단계 | 기대 결과 |
| --- | --- |
| Work 열기 | 웹 화면에서 Work를 고를 수 있다. 파일 4개가 첨부된다 |
| 요청 1 | 작업 계획이 먼저 나온다. 화면 구성 6개(환불 계산, 주차 계산, 결과의 근거 조문, 질문 검색, 담당 부서 표, 상담 창)와 완료 기준이 계획에 있다. 승인하면 몇 분 뒤 미리보기가 열린다 |
| 확인 세 가지 | 요가 40,000원·진행 2회 → 26,000원과 체육시설 이용 규정 제7조 제1항 제2호. 경차·새별역·2시간 40분 → 2,450원. 「대관」 검색 → 문화센터 운영팀(내선 2301) |
| 목과 실제 구분 | 환불 계산, 주차 계산, 질문 검색, 담당 부서 표는 실제로 동작한다. 상담 창은 정해 둔 답만 보여 주는 목이다 |
| 요청 3 | 근거 조문이 금액 바로 아래에 굵게 나오고, 결과 아래에 고객지원팀 내선 안내 문장이 붙는다. 금액은 그대로다 |
| 공개 범위 | 공유 화면에서 선택지를 보고, 시범 운영에 쓸 범위와 이유를 구분표에 적는다. 사이트는 비공개로 남는다. 인터넷 전체에 공개하는 범위를 고르면 누구나 사이트에 들어올 수 있다는 점을 이유에 적는다 |

Work와 Sites의 화면 순서와 공유 화면은 강사가 강의 전날 Plus 계정으로 확인합니다. 한국 계정에서 Sites를 쓸 수 있는지는 공식 문서에 국가 목록이 없어 그날 확인한 결과를 따릅니다.

## 대체 경로(Chat → HTML 파일)

ChatGPT가 만든 파일을 파일 링크로 내려받을 수 있고 그 링크가 빨리 만료된다는 것은 공식 도움말에 있습니다. 다만 Chat이 HTML 파일을 만들어 링크로 주는지는 확인하지 못했습니다. 강사가 강의 전날 확인하고, 링크가 없으면 코드 상자를 복사해 저장하는 방법으로 안내합니다.

강사 사전 실행(codex)에서 「요청 1-파일」로 만든 파일이 `완성본/index.html`입니다. codex는 파일을 작업 폴더에 바로 썼으므로, 이 실행에서는 내려받기 단계를 확인하지 않았습니다. 그 파일을 헤드리스 Chrome으로 열어 아래 값을 직접 입력해 확인했습니다.

| 입력 | 화면에 나온 값 | 근거로 나온 조문 |
| --- | --- | --- |
| 요가 40,000원, 2회 진행 | 26,000원 | 체육시설 이용 규정 제7조 제1항 제2호·제5항 |
| 수영 중급 60,000원, 시작일 전날 신청 | 60,000원 | 제7조 제1항 제1호 |
| 수영 초급 60,000원, 6회 진행 | 0원(환불 없음) | 제7조 제1항 제3호 |
| 아쿠아로빅 50,000원, 3회 진행, 진단서 | 31,250원 | 제7조 제1항 제2호·제2항 제1호 또는 제2호·제5항 |
| 헬스 45,000원, 11월 1일 시작, 11월 10일 신청 | 25,500원 | 제7조 제4항·제5항 |
| 경차, 새별역, 2시간 40분 | 2,450원 | 공영주차장 운영 지침 제4조 제1항, 제5조 제1항 제3호, 제7조 |
| 장애인 표지 + 전기차, 1시간 5분 | 440원 | 제5조 제1항 제1호, 제5조 제2항, 제7조 |
| 경차, 체육센터 주차장, 3시간 10분, 이용 확인 | 1,050원 | 제4조 제2항, 제5조 제1항 제3호 |
| 새별역, 23시간 | 12,000원(1일 최대) | 제4조 제1항 |
| 검색 「대관」 | 2건, 문화센터 운영팀(2301) | 담당 부서 안내 |
| 검색 「수영복」 | 0건, 담당 부서 표가 나온다 | - |

- 파일을 열 때 콘솔 오류 0건, 인터넷 요청 0건이었다.
- 이름·전화번호·주민등록번호를 받는 입력 칸이 없다.
- 휴대폰 폭(390px)에서 담당 부서 표는 표 안에서 가로로 넘겨 본다. 화면 전체가 가로로 넘치지는 않는다.
- ChatGPT Chat이 만든 파일은 이 완성본과 모양이 다릅니다. 값과 근거 조문이 같으면 됩니다.

## 막혔을 때

| 증상 | 할 일 |
| --- | --- |
| Work가 보이지 않는다 | 대체 경로로 간다 |
| 계획이 나오지 않고 바로 만든다 | 그대로 두고 미리보기에서 확인 세 가지를 한다. 계획 승인 장면은 강사 화면으로 본다 |
| 계획은 나왔는데 승인 단추가 보이지 않는다 | 같은 대화에 「계획을 승인한다. 이 계획대로 만들어 줘」를 보낸다. 그래도 만들기가 시작되지 않으면 대체 경로로 간다. 문서는 계획을 고치거나 승인할 수 있다고만 적고 글로 승인하는 방법은 적지 않아, 강사가 강의 전날 확인한다 |
| 사용량 한도 안내나 크레딧 구매 화면이 나온다 | 사지 않는다. 대체 경로로 가거나 `완성본/index.html`을 연다 |
| 값이 틀리다 | 「요청 2」에 입력, 나온 값, 기대 값과 근거를 적어 보낸다 |
| 내려받기 링크를 누르면 「다운로드 실패」나 「파일을 찾을 수 없음」이 나온다 | 링크가 만료되었을 수 있다. 같은 대화에 「index.html을 다시 만들어 줘」를 보내 새 링크를 받는다 |
| 내려받은 파일이 열리지 않는다 | 파일 이름이 `index.html`인지, 확장자가 `.txt`로 바뀌지 않았는지 본다. 그래도 안 되면 `완성본/index.html`을 연다 |
| 공유 화면이 보이지 않는다 | 미리보기까지만 하고, 공개 범위는 구분표에 적는다 |
