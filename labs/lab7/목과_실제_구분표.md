# 목과 실제 구분표

화면의 각 부분이 실제로 계산하거나 찾는지, 정해 둔 답만 보여 주는지(목) 직접 눌러 보고 적습니다. 목인 부분은 동료에게 보여 줄 때 「목」이라고 먼저 말합니다.

| 화면 부분 | 확인한 방법 | 실제로 동작한다 / 목이다 | 근거 조문이 같이 나오는가 | 비고 |
| --- | --- | --- | --- | --- |
| 수강료 환불 계산 | 진행 횟수를 바꿔 금액이 바뀌는지 본다 | | | |
| 주차 요금 계산 | 주차 시간과 감면 대상을 바꿔 본다 | | | |
| 자주 묻는 질문 검색 | 「대관」, 「정기권」, 결과가 없는 낱말(예: 「수영복」)을 넣어 본다 | | 해당 없음 | |
| 담당 부서 안내 | 표가 `자료/새별_담당부서_안내.md`와 같은지 본다 | | 해당 없음 | |
| 상담 창 | 예시에 없는 질문을 넣어 본다 | | | |

목인 부분을 실제로 동작하게 하려면 무엇이 더 필요한가(한 줄): ____

시범 운영에 쓴다면 공개 범위(공유 화면의 선택지 가운데 하나)와 그 이유(한 줄): ____

실습에서는 공개 범위를 정하기만 하고 게시하지 않습니다.
