공공기관 AX 업무혁신 전문가과정 · 2026-11-27 · 부산대학교 경제통상관 L103호

> 이 실습 묶음에 나오는 새별시설공단, 새별시, 등장인물, 규정, 민원, 수치는 모두 실습을 위해 만든 가상 사례입니다. 실제 기관이나 인물과 관계가 없습니다.

## 준비물

- ChatGPT Plus 계정(웹 브라우저로 로그인)
- 이 실습 묶음(`labs/` 폴더). GitHub 저장소 `github.com/revfactory/pusan-univ-ax-deck`에서 받습니다. GitHub 로그인은 필요 없습니다

프로그램 설치, API 키, 추가 결제는 필요 없습니다. `.md` 파일은 컴퓨터에 이미 있는 메모장(Windows)이나 텍스트 편집기(macOS)로 엽니다.

## 파일 다루기

- 실습 묶음은 GitHub 저장소 `github.com/revfactory/pusan-univ-ax-deck`에서 초록색 「Code」 단추 → 「Download ZIP」으로 받습니다. 받은 압축 파일(.zip)을 풀어 내 컴퓨터(예: 바탕 화면)에 두면, 그 안의 `labs` 폴더가 실습 묶음입니다. 파일을 열고 저장하고 ChatGPT에 첨부할 때는 압축을 푼 폴더 안의 파일을 씁니다.
- `.md` 파일은 Windows에서는 메모장, macOS에서는 텍스트 편집기로 엽니다. 다른 프로그램이 열리면 Windows는 파일을 오른쪽 클릭하고 「연결 프로그램」에서, macOS는 파일을 Control-클릭하고 「다음으로 열기」에서 고릅니다. 파일이 열리지 않으면 손을 듭니다.
- 붙여 넣을 요청문은 `` ```text `` 줄과 `` ``` `` 줄 사이에 있습니다. 두 줄 사이의 글만 복사합니다. `` ```text `` 줄과 `` ``` `` 줄은 복사하지 않습니다.
- 고른 글은 복사하고(Windows는 Ctrl+C, macOS는 Command+C), ChatGPT 입력창에 붙여 넣습니다(Windows는 Ctrl+V, macOS는 Command+V).
- 채운 양식은 메모장이나 텍스트 편집기에서 같은 이름으로 저장합니다(Windows는 Ctrl+S, macOS는 Command+S).
- 실습마다 저장할 파일은 각 `labN/단계.md`의 「파일 다루기」 끝에 적혀 있습니다.

## 실습 규칙

1. 이 묶음의 가상 자료만 입력합니다. 소속 기관의 내부 문서, 실제 민원, 실제 개인정보를 넣지 않습니다.
2. LAB-1을 시작하기 전에 설정 → 데이터 관리에서 「모델 개선을 위한 데이터 학습 허용」을 끕니다(`lab1/단계.md`의 「시작 전에」). 끄면 그 뒤에 시작한 새 대화부터 모델 학습에 쓰이지 않습니다. 설정을 꺼도 답변에 좋아요·싫어요 같은 피드백을 보내면 그 대화는 학습에 쓰일 수 있습니다. 끌지 말지는 내가 정합니다.
3. 답변의 조문 번호와 금액은 규정 원문과 직접 대조합니다.
4. 사이트 공개, 공유 링크 열기처럼 밖으로 나가는 행동 앞에서는 공개 범위를 먼저 확인합니다.
5. 사용량 한도를 다 쓰면 크레딧 구매 화면이 나올 수 있습니다. 그 화면이 나오면 사지 않습니다. 강사가 안내하는 대체 경로로 갑니다.

## 막혔을 때

1. `labN/기대결과.md`의 「막혔을 때」를 봅니다.
2. 그래도 안 되면 `labN/완성본/`의 파일로 다음 단계를 이어 갑니다.
3. 결과가 강사 화면과 문장이 달라도 괜찮습니다. 금액, 근거 조문, 판정이 같으면 됩니다.
