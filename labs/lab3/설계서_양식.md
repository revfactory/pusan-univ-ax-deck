# 민원 상담 프로젝트 설계서 양식

프로젝트를 만들기 전에 사람이 정하는 것을 적는 한 장입니다. 각 칸은 확인할 수 있는 문장으로 씁니다(예: 「답변 끝에 근거 조문 번호를 적는다」).

| 칸 | 적을 내용 | 세 항목 요청문에서 가져오는 곳 | 내 설계 |
| --- | --- | --- | --- |
| 1. 역할과 범위 | 누구의 무슨 일을 돕는가, 어느 민원 유형만 다루는가 | 항목 1의 목적, LAB-2의 시범 범위 | |
| 2. 프로젝트 파일 | 근거로 쓰는 파일 이름 | 항목 2의 참고 자료 | |
| 3. 답변 형식 | 칸의 이름과 순서 | 항목 1의 결과물 형식 | |
| 4. 금지와 담당자에게 넘기는 조건 | 하지 않는 일, 담당자 확인으로 넘기는 경우와 넘길 부서 | 항목 2의 제외 범위 | |
| 5. 완료 기준 | 답변 하나가 「쓸 수 있다」고 판단하는 기준 | 항목 3 | |
