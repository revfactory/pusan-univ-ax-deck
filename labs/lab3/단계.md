# LAB-3 「새별 민원 상담」 프로젝트 만들기

> 가상 사례 실습입니다. 맞춤형 GPT 만들기 화면은 쓰지 않습니다. 개인 계정에서는 새 GPT를 만들 수 없습니다.

## 파일 다루기

- 실습 묶음은 GitHub 저장소 `github.com/revfactory/pusan-univ-ax-deck`에서 초록색 「Code」 단추 → 「Download ZIP」으로 받습니다. 받은 압축 파일(.zip)을 풀어 내 컴퓨터(예: 바탕 화면)에 두면, 그 안의 `labs` 폴더가 실습 묶음입니다. 파일을 열고 저장하고 ChatGPT에 첨부할 때는 압축을 푼 폴더 안의 파일을 씁니다.
- `.md` 파일은 Windows에서는 메모장, macOS에서는 텍스트 편집기로 엽니다. 다른 프로그램이 열리면 Windows는 파일을 오른쪽 클릭하고 「연결 프로그램」에서, macOS는 파일을 Control-클릭하고 「다음으로 열기」에서 고릅니다. 파일이 열리지 않으면 손을 듭니다.
- 붙여 넣을 요청문은 `` ```text `` 줄과 `` ``` `` 줄 사이에 있습니다. 두 줄 사이의 글만 복사합니다. `` ```text `` 줄과 `` ``` `` 줄은 복사하지 않습니다.
- 고른 글은 복사하고(Windows는 Ctrl+C, macOS는 Command+C), ChatGPT 입력창에 붙여 넣습니다(Windows는 Ctrl+V, macOS는 Command+V).
- 채운 양식은 메모장이나 텍스트 편집기에서 같은 이름으로 저장합니다(Windows는 Ctrl+S, macOS는 Command+S).
- 이 실습에서 저장할 파일: `설계서_양식.md`(직접 쓴 경우). 확인 질문의 결과가 기대 결과와 다르면 `lab4/시험기록_양식.md`에 옮겨 적습니다. 지침은 프로젝트 설정에 저장합니다

## 실습 순서

1. 사이드바에서 새 프로젝트를 만들고 이름을 「새별 민원 상담」으로 합니다. 단추 이름과 자리는 강사 화면에서 봅니다.
2. 프로젝트 설정의 지침 칸에 `지침_1판.md`의 상자 안 글을 붙여 넣고 저장합니다. 설정을 여는 단추와 저장 단추는 강사 화면에서 봅니다. 모두 지침 1판으로 시작합니다. 파트 2 6장 실습의 기대 결과와 옆 사람과 시험 나누기가 지침 1판을 기준으로 하기 때문입니다.
3. 프로젝트 파일에 아래 3개를 올립니다. 파일 올리기 단추는 강사 화면에서 봅니다.
   - `자료/새별_체육시설_이용규정.md`
   - `자료/새별_공영주차장_운영지침.md`
   - `자료/새별_담당부서_안내.md`
4. 프로젝트 안에서 새 대화를 열고 `확인질문.md`의 Q1\~Q5를 하나씩 보냅니다. 같은 대화에 보내고, 답이 다 나오면 다음 상자를 보냅니다.
5. `기대결과.md`와 견줍니다. 다른 점은 LAB-4의 시험 기록에 옮겨 적습니다.
6. (선택) 5번까지 마치고 시간이 남으면 설계서를 직접 써 봅니다. 수업 시간을 따로 두지 않습니다. 이 실습 시간 안에서 하고, 못 하면 수업 뒤에 해도 됩니다.
   - `설계서_양식.md`를 메모장(macOS는 텍스트 편집기)으로 열고, LAB-1에서 저장한 `lab1/세항목_요청문_양식.md`의 내용을 칸마다 「내 설계」에 옮겨 적고 저장합니다.
   - 「요청 1」로 내 설계서를 지침으로 바꿔 받아 지침 1판과 견줘 봅니다. 프로젝트의 지침 칸은 지침 1판 그대로 둡니다.
