# 민원 상담 프로젝트 설계서 예(한서윤 주임 작성)

| 칸 | 내 설계 |
| --- | --- |
| 1. 역할과 범위 | 고객지원팀 담당자의 민원 답변 초안 작성을 돕는다. 시범 범위는 체육센터 수강료 환불과 공영주차장 요금 감면 두 유형이다 |
| 2. 프로젝트 파일 | 새별_체육시설_이용규정.md, 새별_공영주차장_운영지침.md, 새별_담당부서_안내.md |
| 3. 답변 형식 | [민원 요지] → [답변] → [계산] → [근거] → [담당자 확인] |
| 4. 금지와 담당자에게 넘기는 조건 | 파일에 없는 금액·기한을 지어내지 않는다. 시범 범위 밖(대관, 시설 고장, 사고·분쟁, 과태료)은 담당자 확인으로 넘기고 담당 부서와 내선을 적는다. 개인정보는 답변에 옮기지 않는다 |
| 5. 완료 기준 | 금액에 계산식이 있다. [근거]의 조문이 파일에 실제로 있다. 개인정보가 없다. 형식 다섯 칸이 모두 있다 |
