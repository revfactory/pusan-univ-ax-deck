# LAB-6 승인 요약 쓰고 승인받기

> 가상 사례 실습입니다. 이 묶음의 가상 자료만 입력합니다.

## 파일 다루기

- 실습 묶음은 GitHub 저장소 `github.com/revfactory/pusan-univ-ax-deck`에서 초록색 「Code」 단추 → 「Download ZIP」으로 받습니다. 받은 압축 파일(.zip)을 풀어 내 컴퓨터(예: 바탕 화면)에 두면, 그 안의 `labs` 폴더가 실습 묶음입니다. 파일을 열고 저장하고 ChatGPT에 첨부할 때는 압축을 푼 폴더 안의 파일을 씁니다.
- `.md` 파일은 Windows에서는 메모장, macOS에서는 텍스트 편집기로 엽니다. 다른 프로그램이 열리면 Windows는 파일을 오른쪽 클릭하고 「연결 프로그램」에서, macOS는 파일을 Control-클릭하고 「다음으로 열기」에서 고릅니다. 파일이 열리지 않으면 손을 듭니다.
- 붙여 넣을 요청문은 `` ```text `` 줄과 `` ``` `` 줄 사이에 있습니다. 두 줄 사이의 글만 복사합니다. `` ```text `` 줄과 `` ``` `` 줄은 복사하지 않습니다.
- 고른 글은 복사하고(Windows는 Ctrl+C, macOS는 Command+C), ChatGPT 입력창에 붙여 넣습니다(Windows는 Ctrl+V, macOS는 Command+V).
- 채운 양식은 메모장이나 텍스트 편집기에서 같은 이름으로 저장합니다(Windows는 Ctrl+S, macOS는 Command+S).
- 이 실습에서 저장할 파일: `승인요약_양식.md`(아래의 승인 기록 칸까지), `팀장_판정카드.md`(옆 사람이 내 노트북에서 채운다)

## 실습 순서

LAB-4의 시험 기록과 LAB-5의 판정 기록으로 팀장에게 올릴 승인 요약 한 장을 만들고, 옆 사람이 팀장 역할을 맡아 판정합니다.

1. 내 시험 기록(`lab4`에서 채운 `시험기록_양식.md`)을 준비합니다. 없으면 `완성본/시험기록_예.md`를 씁니다.
2. ChatGPT에서 새 대화를 열고 「요청 1」 아래에 시험 기록을 붙여 넣어 보냅니다. LAB-5 판정 기록이 있으면 그 아래에 함께 붙입니다.
3. 받은 초안을 `승인요약_양식.md`에 옮기고 내가 직접 고칩니다.
   - [시험 결과]의 숫자를 시험 기록과 한 줄씩 대조합니다. 다르면 시험 기록의 숫자로 고칩니다.
   - 시험 기록에 없는 내용(예: 「정확도 95%」)이 들어가 있으면 지웁니다.
4. 옆 사람과 승인 요약을 바꿉니다.
   - 바꾸기 전에 각자 내 노트북에 세 파일을 열어 둡니다: 내가 고친 `승인요약_양식.md`, 내 시험 기록(`lab4/시험기록_양식.md`, 없으면 `완성본/시험기록_예.md`), `팀장_판정카드.md`.
   - 옆 사람과 노트북을 바꿉니다. 6번까지 옆 사람 노트북에서 적은 뒤 돌려줍니다.
   - 옆 사람의 승인 요약을 `팀장_판정카드.md`의 질문 5개로 읽고, 승인·수정 요청·보류 가운데 하나로 판정합니다. 판정카드도 옆 사람 노트북의 파일에 적고 저장합니다.
5. 판정한 사람이 `승인요약_양식.md` 아래의 승인 기록 칸(날짜, 판정, 조건, 판정한 사람)을 채웁니다.
6. 승인이면 「새별 민원 상담」 프로젝트를 누구와 공유할지 승인 기록의 조건 칸에 적습니다. 이 실습에서는 공유 링크를 실제로 열지 않습니다.

## 요청 1

```text
아래 시험 기록으로 팀장에게 올릴 승인 요약 초안을 써 줘. 한 장 분량으로, 아래 네 칸만 쓴다.

[만든 것] 프로젝트 이름, 다루는 민원 두 가지, 근거로 쓰는 파일, 답변 형식
[시험 결과] 시험 수, 통과 수, 규칙 시험(개인정보, 지시 바꾸기) 결과, 고친 지침과 고친 뒤 결과
[남는 위험] 시험 기록의 「남는 위험」과, 시험하지 않은 범위
[사람이 정할 것] 팀장이 정할 것: 시범 기간, 쓸 사람과 공유 범위(Plus 계정의 프로젝트 공유는 최대 10명), 발송 전 확인 방법

시험 기록에 없는 숫자나 결과를 지어내지 않는다. 시험 기록으로 알 수 없는 칸은 「확인 필요」라고 쓴다.

(여기에 시험 기록을 붙여 넣는다)
```

## 공유 범위를 정할 때 알아 둘 것

- Plus 계정 소유자는 프로젝트에 최대 10명까지 초대할 수 있습니다.
- 링크로 누구나 들어오게 열면, 링크를 받은 로그인한 ChatGPT 사용자는 누구나 들어올 수 있습니다.
- 편집 권한을 받은 사람은 지침과 파일을 고치고 다른 사람을 초대할 수 있습니다. 편집 권한이 없는 참여자는 보고 대화만 합니다.
- 공유 메뉴와 권한의 화면 이름은 강사가 안내합니다. 한국어 도움말(기계 번역)은 공유 대상을 「초대받은 사용자만」, 「링크가 있는 모든 사용자」로, 권한을 「채팅 또는 편집 액세스」로 적습니다.
- 공유 프로젝트의 대화는 소유자와 모든 참여자가 「모델 개선을 위한 데이터 학습 허용」을 켠 경우에만 모델 개선에 쓰일 수 있습니다.
