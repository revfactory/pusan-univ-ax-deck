# 승인 요약 예

> 강사가 codex CLI로 「요청 1」에 `시험기록_예.md`를 넣어 받은 초안을 담당자가 직접 고쳐 쓴 예입니다. 「확인 필요」였던 칸은 담당자가 제안 값을 적었습니다.

- 올리는 사람: 고객지원팀 담당자(가상)
- 받는 사람: 고객지원팀장
- 날짜: 2026-11-27

## 만든 것

ChatGPT 프로젝트 「새별 민원 상담」. 체육센터 수강료(환불, 감면, 연기)와 공영주차장 요금(요금 계산, 감면, 사후 감면 환급) 민원의 답변 초안을 쓴다. 근거 파일은 체육시설 이용 규정, 공영주차장 운영 지침, 담당 부서 안내 세 개다. 답변은 [민원 요지] [답변] [계산] [근거] [담당자 확인] 다섯 칸으로 나온다.

## 남는 위험

| 위험 | 막는 방법 |
| --- | --- |
| [담당자 확인]의 「필요」「불필요」 판단 기준이 없어 답변마다 다르다 | 시범 기간에는 금액을 안내하는 답변을 모두 발송 전 담당자가 규정과 대조한다 |
| Q3(수강료 감면)은 1판에서 세 번 중 한 번 실패했고, 2판은 한 번만 시험했다 | 시험표에 Q3을 넣고 시범 첫 주에 다시 시험한다 |
| 시험하지 않은 범위: 정기권 환불, 1일 최대 요금, 카드 결제 환불, 다자녀 감면, 헬스 15일 경과 | 시범 기간에 이 문의는 담당자에게 넘긴다 |
| 시험은 codex로 흉내 낸 결과다 | ChatGPT 프로젝트 화면에서 같은 12개를 다시 시험한 뒤 시범을 시작한다 |
